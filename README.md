# Email Finder GUI & Excel Multi-Sheet Generator

This repository is set up to automatically compile your Python GUI script into a standalone Windows `.exe` file using GitHub Actions.

## How to Build the EXE:
1. Upload `multiple_email_finder_gui.py` and `.github/workflows/build.yml` to your GitHub repository.
2. Go to the **Actions** tab in GitHub to watch the build progress.
3. Download the built application artifact `EmailFinder-GUI-EXE` from the workflow summary page!
